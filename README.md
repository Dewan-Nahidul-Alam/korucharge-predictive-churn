# KoruCharge Customer Churn Analysis

## 📌 Project Overview

As a consultant contracted by **KoruCharge**, the objective of this project was to improve the company’s understanding of customer churn and provide actionable recommendations to enhance customer retention.

The project involved:
- Exploratory Data Analysis (EDA)
- Data preprocessing and feature preparation
- Building and evaluating multiple classification models
- Identifying key churn drivers
- Translating analytical findings into business recommendations for management

## 📊 Responsibilities

- Performed data preprocessing to ensure numerical variable consistency and handle missing values.
- Conducted exploratory data analysis (EDA) to summarize churn distributions across key categorical and numerical variables.
- Partitioned the dataset into training and testing sets using a **70%-30% stratified sampling** approach to reduce overfitting and underfitting risks.
- Applied **5-fold cross-validation** on the training dataset.
- Built and evaluated multiple machine learning algorithms, including:
  - Logistic Regression
  - LightGBM
  - XGBoost
  - Random Forest
  - Naïve Bayes
  - K-Nearest Neighbors (KNN)
- Selected the model with the best overall performance based on evaluation metrics.
- Evaluated the finalized model on unseen test data.

---

## 🏆 Key Achievements

- Identified the **Top 5 key drivers of customer churn** for KoruCharge.
- Achieved:
  - **90.5% Correctness**
  - **89.2% Accuracy**
- Converted analytical findings into actionable business recommendations to improve customer retention.

## 📈 Project Outcome

The analysis enabled KoruCharge management to better understand customer churn behavior and prioritize strategic retention initiatives based on data-driven insights.
